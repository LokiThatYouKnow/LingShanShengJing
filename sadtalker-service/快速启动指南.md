# SadTalker 本地部署 - 快速启动指南

## 目录结构

```
d:/TALKING/
├── sadtalker-service/          # SadTalker推理服务
│   ├── sadtalker_service.py    # 主服务程序
│   ├── requirements.txt        # Python依赖
│   ├── start.bat               # Windows启动脚本
│   ├── uploads/                # 上传文件目录
│   │   ├── audio/             # 音频文件
│   │   └── images/            # 形象图片
│   ├── output/                 # 输出视频目录
│   └── checkpoints/           # 模型权重目录
│
└── scenic-guide-springboot/    # Spring Boot后端
    └── ...
```

## 快速启动（5步）

### Step 1: 下载SadTalker模型（约18GB）

```bash
# 在Windows上使用Git Bash或PowerShell
cd d:/TALKING/sadtalker-service/checkpoints

# 克隆官方仓库
git clone https://github.com/OpenTalker/SadTalker.git SadTalker

# 下载预训练权重（百度网盘更快）
# 链接: https://pan.baidu.com/s/1ACgFv3E3KQv4O3TVtKkZ6A
# 密码: sadt

# 解压到 checkpoints/SadTalker/ 目录
```

### Step 2: 准备形象图片

下载一张正面照（建议512x512 PNG）：
- https://this-person-does-not-exist.com/
- 或手机自拍一张正面照

保存到：`d:/TALKING/sadtalker-service/uploads/images/default_avatar.png`

### Step 3: 安装Python依赖

```bash
cd d:/TALKING/sadtalker-service

# 安装Python依赖
pip install -r requirements.txt

# 如果没有PyTorch，安装GPU版本
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu118
```

### Step 4: 启动SadTalker服务

```bash
# Windows
cd d:/TALKING/sadtalker-service
start.bat

# 或手动启动
python sadtalker_service.py
```

看到以下输出表示启动成功：
```
========================================
 SadTalker Local Service
========================================
[INFO] Initializing SadTalker...
[HTTP] Static file server started on http://localhost:8001
[WS] Starting WebSocket server on ws://localhost:8002
[READY] SadTalker service ready!
       - HTTP: http://localhost:8001
       - WebSocket: ws://localhost:8002
========================================
```

### Step 5: 启动Spring Boot后端

```bash
cd d:/TALKING/scenic-guide-springboot

# 如果还没编译
mvn clean package -DskipTests

# 启动
java -jar target/scenic-guide-1.0.0.jar --server.port=8080
```

## 常见问题

### Q1: CUDA out of memory
**解决**：降低分辨率或关闭GFPGAN增强
```python
# 修改 sadtalker_service.py
kwargs = {
    'size': 256,  # 从512降到256
    'enhancer': None,  # 关闭面部增强
}
```

### Q2: 模型文件找不到
**解决**：确保模型解压到正确目录
```
checkpoints/
└── SadTalker/
    └── SadTalker/
        ├── SadTalker.tar.gz (解压)
        └── gfpgan/
```

### Q3: 生成太慢
**解决**：
- 使用模拟模式测试前端（无需GPU）
- 或降低分辨率 `size=256`

## 性能优化

| 设置 | 显存需求 | 生成速度 | 质量 |
|------|----------|----------|------|
| 512p + GFPGAN | 8GB+ | 15-30秒 | 最佳 |
| 512p 无增强 | 6GB+ | 10-20秒 | 较好 |
| 256p 无增强 | 4GB+ | 5-10秒 | 一般 |

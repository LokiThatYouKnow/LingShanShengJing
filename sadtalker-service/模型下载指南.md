# SadTalker 模型下载指南

## 官方推荐方法

### 方法1: 使用Git LFS克隆（推荐）

```bash
cd d:/TALKING/sadtalker-service/checkpoints

# 克隆SadTalker官方仓库
git clone https://github.com/OpenTalker/SadTalker.git SadTalker

# 进入目录
cd SadTalker

# 查看checkpoints目录
ls checkpoints/
```

### 方法2: 手动下载模型权重

从Google Drive或HuggingFace下载：

| 模型 | 大小 | 用途 |
|------|------|------|
| SadTalker_LiSu.tar.gz | ~18GB | 写实风格女声 |
| SadTalker_FaceCap.tar.gz | ~18GB | 面部捕捉 |

**HuggingFace下载**: https://huggingface.co/vinthony/SadTalker
**百度网盘**: https://pan.baidu.com/s/1ACgFv3E3KQv4O3TVtKkZ6A (密码: sadt)

### 方法3: 使用预训练权重（简化版）

如果不追求最高质量，可以下载轻量版本：

```bash
# 在 checkpoints 目录下执行
mkdir -p SadTalker
cd SadTalker

# 下载基础权重
curl -L -o mapping_00189-Generation.npy https://huggingface.co/vinthony/SadTalker/resolve/main/checkpoints/mapping_00189-Generation.npy
curl -L -o mapping_00229-Generation.npy https://huggingface.co/vinthony/SadTalker/resolve/main/checkpoints/mapping_00229-Generation.npy
curl -L -o SadTalker_LiSu.tar.gz https://huggingface.co/vinthony/SadTalker/resolve/main/checkpoints/SadTalker_LiSu.tar.gz
```

## 模型目录结构

```
d:/TALKING/sadtalker-service/checkpoints/
└── SadTalker/
    ├── SadTalker_LiSu.tar.gz (解压后)
    │   ├── SadTalker/
    │   │   ├── checkpoint
    │   │   │   └── ...
    │   │   ├── SadTalker.tar.gz
    │   │   └── ...
    │   └── gfpgan
    │       └── ...
    └── mapping_00189-Generation.npy
    └── mapping_00229-Generation.npy
```

## 解压模型

```bash
cd d:/TALKING/sadtalker-service/checkpoints/SadTalker

# 解压主模型
tar -xzf SadTalker_LiSu.tar.gz

# 解压内部tar
cd SadTalker
tar -xzf SadTalker.tar.gz
```

## 快速测试

1. 下载好模型后，准备好一张正面照 (512x512 PNG)
2. 准备一段WAV音频
3. 运行测试:

```bash
cd d:/TALKING/sadtalker-service
python -c "
from SadTalker.inference import SadTalker
print('SadTalker import OK!')
"
```

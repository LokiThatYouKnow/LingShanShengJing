【服务端口】

【CORS 配置要点】

  Spring Boot 需要同时配置两层 CORS：

  1. SecurityConfig — Spring Security 过滤器层
     corsConfigurationSource() → setAllowedOriginPatterns(...)

  2. WebMvcConfig — Spring MVC 拦截器层
     addCorsMappings(CorsRegistry) → .allowedOriginPatterns(...)

  两层的 allowedOriginPatterns 必须一致，否则 MVC 层的 DefaultCorsProcessor
  会在 Security 过滤器放行后仍然返回 403 "Invalid CORS request"。

  推荐模式列表：
    "http://localhost:*"
    "http://127.0.0.1:*"
    "https://*.你的生产域名"

  ⚠ 不要同时使用 setAllowedOrigins("*") + setAllowCredentials(true)，
    浏览器规范禁止 credentials 配合通配符 origin。


【本地开发启动顺序】

  1. Docker Desktop  → MySQL 3306, Redis 6379
  2. Spring Boot     → 8080 (java -jar 或 mvn spring-boot:run)
  3. FastAPI         → 8000 (uvicorn main:app --reload)
  4. (可选) SadTalker → 8001 (需要 GPU)
  5. Kiosk 前端      → 5174 (npm run dev)
  6. Admin 前端      → 5175 (npm run dev)


【端口冲突排查】

  # 查端口占用
  netstat -ano | grep ":8000 " | grep LISTENING

  # 查进程名
  tasklist | grep <PID>

  # 强制结束
  taskkill /F /PID <PID>

  # 常见问题：
  - 8000 被其他 Python 进程占用 → 旧的 uvicorn 残留，kill 全部 python.exe
  - 8080 无 LISTEN → Spring Boot 启动失败，检查 application.yml 数据库连接
  - 5174/5175 端口冲突 → 改 vite.config.js 里的 server.port

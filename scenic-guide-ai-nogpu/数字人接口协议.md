## 二、WebSocket 信令协议

### 连接地址
```
ws://localhost:8080/api/digital-human/stream
```

### 2.1 客户端 → 服务端 消息

#### 开始说话
```json
{
  "type": "speak",
  "text": "您好！欢迎来到灵山胜境...",
  "audioUrl": "https://cdn.example.com/audio/xxx.mp3",
  "emotion": "happy",
  "clientTime": 1704451200000
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| type | string | ✅ | 固定 `speak` |
| text | string | ✅ | 回复文本（用于字幕） |
| audioUrl | string | ✅ | 音频文件URL |
| emotion | string | ❌ | 情感标签：`happy`/`sad`/`neutral`/`excited` |
| clientTime | number | ✅ | 客户端发送时间戳（用于延迟计算） |

#### 倾听状态
```json
{
  "type": "listening"
}
```

#### 思考状态
```json
{
  "type": "thinking"
}
```

#### 心跳
```json
{
  "type": "ping",
  "timestamp": 1704451200000
}
```

---

### 2.2 服务端 → 客户端 消息

#### 状态变更
```json
{
  "type": "state",
  "state": "speaking",
  "timestamp": 1704451200100
}
```

`state` 可选值：
- `idle` - 待机
- `listening` - 倾听中
- `thinking` - 思考中
- `speaking` - 说话中
- `error` - 错误

#### 音画同步
```json
{
  "type": "sync",
  "timestamp": 1704451200500,
  "videoTime": 1.245
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| timestamp | number | 服务端时间戳 |
| videoTime | number | 当前视频播放时间（秒） |

#### 播放结束
```json
{
  "type": "end"
}
```

#### 错误
```json
{
  "type": "error",
  "message": "音频文件不存在"
}
```

#### 心跳响应
```json
{
  "type": "pong",
  "echo": 1704451200000,
  "latency": 45
}
```

---

### 2.3 视频流传输

**传输方式**：WebSocket二进制帧

服务端主动推送视频数据块（chunks），格式为 `video/webm` 分片：

```
[Binary Frame 1] → [Binary Frame 2] → [Binary Frame 3] → ...
```

每个chunk大小建议 64KB - 256KB，用于MSE的 `SourceBuffer.appendBuffer()`。

## 四、后端需要实现的部分

### 4.1 WebSocket Handler（重点）

```java
// DigitalHumanWebSocketHandler.java

@RestController
@RequestMapping("/api/digital-human")
public class DigitalHumanController {
    
    @GetMapping("/config")
    public DigitalHumanConfig getConfig() {
        // 返回当前数字人配置
        return new DigitalHumanConfig(
            "wav2lip",           // 驱动引擎
            "mei_ren",          // 形象ID
            "温柔女声",           // 音色
            1.0,                // 语速
            1.0                 // 音调
        );
    }
}
```

```java
// 需要新建 WebSocket 配置类
@Configuration
@EnableWebSocket
public class WebSocketConfig implements WebSocketConfigurer {
    
    @Override
    public void registerWebSocketHandlers(WebSocketHandlerRegistry registry) {
        registry.addHandler(digitalHumanHandler(), "/api/digital-human/stream")
                .setAllowedOrigins("*");
    }
    
    @Bean
    public WebSocketHandler digitalHumanHandler() {
        return new DigitalHumanStreamHandler();
    }
}
```

```java
// DigitalHumanStreamHandler.java
public class DigitalHumanStreamHandler extends TextWebSocketHandler {
    
    // 处理文本消息（信令）
    @Override
    protected void handleTextMessage(WebSocketSession session, TextMessage message) {
        JsonObject json = JsonParser.parseString(message.getPayload()).getAsJsonObject();
        String type = json.get("type").getAsString();
        
        switch (type) {
            case "speak":
                handleSpeak(session, json);
                break;
            case "listening":
                handleListening(session);
                break;
            case "thinking":
                handleThinking(session);
                break;
            case "ping":
                handlePing(session, json);
                break;
        }
    }
    
    // 处理二进制消息（视频流）
    @Override
    protected void handleBinaryMessage(WebSocketSession session, BinaryMessage message) {
        // 转发视频数据块给客户端
    }
    
    // 触发数字人渲染并推送视频流
    private void handleSpeak(WebSocketSession session, JsonObject json) {
        String text = json.get("text").getAsString();
        String audioUrl = json.get("audioUrl").getAsString();
        String emotion = json.get("emotion").getAsString();
        
        // 1. 更新状态为 speaking
        sendState(session, "speaking");
        
        // 2. 调用数字人渲染服务（这里需要集成 Wav2Lip/DINet）
        digitalHumanService.render(text, audioUrl, emotion, (videoChunk) -> {
            // 3. 推送视频数据块
            try {
                session.sendMessage(new BinaryMessage(videoChunk));
            } catch (IOException e) {
                e.printStackTrace();
            }
        });
        
        // 4. 定期发送同步时间戳
        startSyncTimer(session);
    }
}
```

### 4.2 数字人渲染服务（核心）

你需要集成以下服务之一：

#### 方案A：Wav2Lip（推荐，开源效果好）
```python
# render_service.py
import asyncio
from Wav2Lip import inference as w2l

async def render(text, audio_url, emotion, on_chunk):
    # 1. 下载音频
    audio_path = await download_audio(audio_url)
    
    # 2. 生成口型同步视频
    video_path = w2l.generate(
        video_path='models/avatar_base.mp4',
        audio_path=audio_path,
        img_size=512
    )
    
    # 3. 转换为webm分片并推送
    for chunk in stream_video(video_path, chunk_size=128*1024):
        on_chunk(chunk)
    
    # 4. 清理临时文件
    cleanup([audio_path, video_path])
```

#### 方案B：第三方数字人API（更快集成）
- 腾讯云数字人
- 阿里云数字人
- 科大讯飞虚拟主播
- 百度智能云数字人

### 4.3 流媒体优化（可选）

如果视频流太大，可以添加转码：

```java
// FFmpeg 转码为低码率 webm
ProcessBuilder pb = new ProcessBuilder(
    "ffmpeg", "-i", "input.mp4",
    "-c:v", "libvpx-vp9",
    "-crf", "35",
    "-b:v", "500k",
    "-vf", "scale=512:-2",
    "-f", "webm",
    "-chunk_duration", "200ms",
    "pipe:1"
);
```

## 五、前端调用示例

```javascript
// 在 KioskView.vue 中使用
<template>
  <AvatarDigitalHuman 
    ws-url="ws://localhost:8080/api/digital-human/stream"
    :debug="true"
    ref="avatarRef"
    @state-change="onStateChange"
  />
</template>

<script setup>
import { ref } from 'vue';
import { useDigitalHumanChat } from '@/composables/useDigitalHumanChat.js';

const avatarRef = ref(null);

const chat = useDigitalHumanChat({
  chatUrl: '/api/chat/message',
  asrUrl: '/api/voice/asr',
  dhWsUrl: 'ws://localhost:8080/api/digital-human/stream'
});

// 发送消息
const handleSend = async (text) => {
  const result = await chat.sendMessage(text, {
    onStartSpeaking: ({ text, audioUrl }) => {
      console.log('开始播放数字人');
    }
  });
  
  if (!result.success) {
    ElMessage.error(result.error);
  }
};

// 语音识别后发送
const handleVoiceInput = async (audioFile) => {
  const result = await chat.recognizeSpeech(audioFile);
  if (result.success) {
    await handleSend(result.text);
  }
};
</script>
```

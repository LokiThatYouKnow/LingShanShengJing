# 景区导览服务AI数字人系统 - 部署手册

## 1. 系统概述

本系统包含四个子系统：
- **后端服务**（FastAPI + Python）：统一API服务
- **手机APP**（UniApp）：游客移动端
- **PC讲解端**（Vue3）：景区大屏讲解机
- **管理后台**（Vue3 + ElementPlus）：景区管理员后台

---

## 2. 环境要求

### 2.1 两种部署模式

本系统支持两种部署模式，根据硬件条件灵活选择：

| 模式 | SadTalker | 数字人效果 | 适用场景 |
|------|-----------|-----------|---------|
| **完整模式** | ✅ 本地部署 | 口型+表情同步的真实数字人视频 | 本地开发 / GPU 服务器 |
| **轻量模式** | ❌ 不部署 | TTS 语音 + Live2D/Q版静态形象 | 云服务器 / 无 GPU 环境 |

> **轻量模式下**，待机视频和开场白视频需在完整模式环境中**预生成**后上传到服务器 `backend_videos` 卷，系统会直接播放预生成视频，游客端体验不受影响。

### 2.2 服务器要求

#### 完整模式（含 SadTalker）— 本地/GPU 服务器

| 组件 | 最低配置 | 推荐配置 |
|------|---------|---------|
| CPU | 6核 | 12核+ |
| RAM | 16GB | 32GB+ |
| **GPU** | **NVIDIA GTX 1660 (6GB VRAM)** | **NVIDIA RTX 3060+ (12GB VRAM)** |
| 存储 | 100GB SSD | 300GB SSD |
| OS | Ubuntu 20.04/22.04 | Ubuntu 22.04 |
| CUDA | 11.7+ | 12.1+ |

> **GPU 是关键**: SadTalker 依赖 CUDA 进行神经网络推理。无 GPU 时单次视频生成耗时 30–120 秒(不可用)，RTX 3060 可将生成时间降至 3–8 秒。

#### 轻量模式（不含 SadTalker）— 云服务器

| 组件 | 最低配置 | 推荐配置 |
|------|---------|---------|
| CPU | 2核 | 4核 |
| RAM | 4GB | 8GB |
| GPU | **不需要** | — |
| 存储 | 30GB SSD | 50GB SSD |
| OS | Ubuntu 20.04+ / OpenCloudOS 9 | Ubuntu 22.04 |

### 2.3 软件依赖
- Python 3.10+
- Node.js 18+
- MySQL 8.0+
- Redis 7.0+（可选，用于缓存）
- FFmpeg（数字人视频处理，**完整模式必需**）
- CUDA 11.7+（**仅完整模式**，SadTalker 推理加速）
- NVIDIA Container Toolkit（Docker GPU 模式）

## 3. 快速开始

### 3.1 克隆项目

```bash
git clone https://github.com/yourname/scenic-guide-ai.git
cd scenic-guide-ai
```

### 3.2 后端部署

```bash
# 进入后端目录
cd backend

# 创建虚拟环境
python -m venv venv
source venv/bin/activate    # Linux/Mac
# 或 venv\Scripts\activate  # Windows

# 安装依赖
pip install -r requirements.txt

# 下载Whisper模型
python -c "import whisper; whisper.load_model('medium')"
```

### 3.3 配置环境变量

```bash
# 复制环境变量模板
cp .env.example .env

# 编辑.env文件，填入以下必要配置
nano .env
```

**.env 关键配置项：**

```ini
# 数据库
DATABASE_URL=mysql+pymysql://root:yourpassword@localhost:3306/scenic_guide

# 大模型API（选择一个）
OPENAI_API_KEY=sk-xxxx
# 或使用国内模型
ZHIPU_API_KEY=xxxx
QWEN_API_KEY=xxxx

# TTS服务
PARATTS_API_KEY=your_paratts_key

# 向量数据库
CHROMA_PERSIST_DIR=./chroma_db

# JWT密钥
SECRET_KEY=your-super-secret-key-change-this

# 跨域设置
CORS_ORIGINS=["http://localhost:5173","http://localhost:5174","http://localhost:5175"]
```

### 3.4 初始化数据库

```bash
# 创建MySQL数据库
mysql -u root -p -e "CREATE DATABASE scenic_guide CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"

# 运行数据库迁移
python -m app.db.init_db

# 导入示例景区数据（可选）
python scripts/import_sample_data.py
```

### 3.5 启动后端服务

```bash
# 开发模式
uvicorn main:app --host 0.0.0.0 --port 8000 --reload

# 生产模式
gunicorn main:app -w 4 -k uvicorn.workers.UvicornWorker --bind 0.0.0.0:8000
```

### 3.6 部署前端（PC讲解端）

```bash
cd ../web-kiosk
npm install
npm run build
# 产物在 dist/ 目录，使用Nginx托管
```

### 3.7 部署管理后台

```bash
cd ../web-admin
npm install
npm run build
# 产物在 dist/ 目录，使用Nginx托管
```

### 3.8 部署手机APP（UniApp）

```bash

# 运行 → 运行到手机或模拟器 或

```

## 4. Nginx 配置示例

```nginx
server {
    listen 80;
    server_name your-domain.com;

    # 后端API代理
    location /api/ {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_read_timeout 120s;
    }

    # 静态文件（API上传）
    location /static/ {
        alias /opt/scenic-guide-ai/backend/static/;
    }

    # 管理后台（端口5175）
    location /admin/ {
        alias /opt/scenic-guide-ai/web-admin/dist/;
        try_files $uri $uri/ /admin/index.html;
    }

    # 大屏讲解端（端口5174）
    location /kiosk/ {
        alias /opt/scenic-guide-ai/web-kiosk/dist/;
        try_files $uri $uri/ /kiosk/index.html;
    }

    # WebSocket支持（数字人实时通信）
    location /ws/ {
        proxy_pass http://127.0.0.1:8000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
    }
}
```

### 5.2 SadTalker 数字人驱动（⭐ 核心组件）

SadTalker 是本系统的核心亮点——基于音频驱动生成**口型同步、表情自然**的数字人讲解视频，让 AI 导游从"会说话的喇叭"升级为"有表情、会说话的虚拟人"。这是本系统区别于传统 TTS 语音导游的本质差异。

#### 5.2.1 SadTalker 工作原理

```
参考图像（数字人形象）
    ─┐
      ├──→ 3D 人脸重建 → 面部动作参数 ─┐
      │                                  ├→ 渲染合成 → 口型同步视频
音频（TTS 生成的讲解语音）               │
      ─┘→ 音频特征提取 → 口型姿态参数 ─┘
```

SadTalker 接收一张参考图像和一段音频，通过 3D 可变形模型(3DMM)从音频中推断口型、头部姿态和眨眼等面部动作，最终渲染出**512×512 分辨率、音频完全同步**的数字人视频。

#### 5.2.2 GPU 推荐配置

SadTalker 对 GPU 显存要求较高，以下为实测数据：

| GPU 型号 | 显存 | 单次生成耗时 | 推荐场景 |
|----------|------|-------------|---------|
| RTX 4090 | 24GB | ~2s | 实时交互生成 |
| RTX 3060 | 12GB | ~5s | **推荐 — 性价比最优** |
| RTX 2060 | 6GB | ~8s | 预生成模式 |
| GTX 1660 | 6GB | ~12s | 最低可用 |
| CPU only | — | 60–120s | **不可用于生产** |

> **生产建议**: RTX 3060 12GB 是最佳性价比选择。互动问答场景用预生成+缓存策略，开场和待机视频提前生成，实时提问时播放缓存视频即可。

#### 5.2.3 安装 SadTalker

```bash
# 1. 克隆 SadTalker 仓库
git clone https://github.com/OpenTalker/SadTalker.git
cd SadTalker

# 2. 创建虚拟环境（SadTalker 要求 Python 3.8–3.10）
conda create -n sadtalker python=3.10
conda activate sadtalker

# 3. 安装 PyTorch（CUDA 版）
pip install torch==2.0.1 torchvision==0.15.2 --index-url https://download.pytorch.org/whl/cu118

# 4. 安装 SadTalker 依赖
pip install -r requirements.txt

# 5. 下载预训练模型（约 2GB）
bash scripts/download_models.sh
# 或手动下载到 checkpoints/ 目录：
#   - SadTalker_V0.0.2_256.safetensors
#   - SadTalker_V0.0.2_512.safetensors
#   - mapping_00229-model.pth.tar
#   - mapping_00109-model.pth.tar
#   - facevid2vid_00189-model.pth.tar
#   - epochs/latest_net_G.pth（GFPGAN 面部增强）
#   - wav2lip.pth（Wav2Lip 口型同步）
```

#### 5.2.4 Docker 部署（完整模式）

项目提供 `sadtalker-service/Dockerfile`（CPU 模式）和 `Dockerfile.gpu`（GPU 模式）：

```bash
# GPU 模式部署（需要 nvidia-container-toolkit）
docker compose -f docker-compose.yml -f docker-compose.gpu.yml up -d sadtalker

# 验证 SadTalker 服务
curl http://localhost:8001/status
```

#### 5.2.5 预生成视频（轻量模式必需）

云服务器不部署 SadTalker 时，需在**本地 GPU 机器**上预生成视频，上传到服务器：

```bash
# 在本地 GPU 机器上生成（6 个视频，约 3 分钟）
# 生成 5 个待机循环视频（idle_01~05.mp4）
python sadtalker-service/generate_idle.py --count 5 --image avatar.png

# 生成开场白视频（opening.mp4）
python sadtalker-service/generate_opening.py --image avatar.png --text "您好，欢迎来到景区！"

# 上传到云服务器
scp idle_*.mp4 opening.mp4 root@your-server:/tmp/videos/

# 在服务器上导入到 Docker 卷
docker cp /tmp/videos/. scenic-backend:/app/videos/
docker compose restart backend
```

#### 5.2.6 环境变量配置

```ini
# SadTalker 服务地址（完整模式下使用）

# 预生成视频目录（轻量模式下使用）
```

## 8. 常见问题

**Q：Whisper识别速度慢？**
A：使用GPU加速，确保安装了CUDA和对应的torch-cuda版本。

**Q：数字人视频生成延迟高？**
A：SadTalker生成耗时约3-8秒，生产环境建议预生成常用讲解视频并缓存，实时使用CSS动画备用方案。

**Q：大模型返回不够准确？**
A：检查知识库文档是否完整上传，调整RAG检索参数（top_k=5，相似度阈值0.7）。

**Q：MySQL连接失败？**
A：检查DATABASE_URL配置，确认MySQL服务运行，允许远程连接权限。
